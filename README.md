# PRIME LAB — 素数の規則性を探索する公開実験

## 研究目的
素数の**予測・生成**と**分布・構造**の両面から、検証可能な規則性を探索する。
双子素数・素数間隔・剰余類の構造に加え、「小さな整数世界を拡張する」という研究構想も今後の定式化候補とする。

## 現在の自動研究
GitHub Actions (`.github/workflows/daily.yml`) が定期実行を試みる。
Gemini APIによる候補生成 → 安全な構造化条件の数値検証 → JSON保存 → 公開データ再生成 → 関連文献の候補検索、という流れ。
`src/prime_lab/research_feedback.py` が過去の実験を要約し、次回の仮説生成に渡す。
候補は最大10件で、重複・不正な候補があれば10件未満となる。
設定上の実行時刻は UTC 01:17（日本時間10:17）。実際の実行成功はActions画面で確認する。

## 現段階の限界
- 過去の結果を**文章として次のAI入力へ反映**する第一段階を実装済み。自動的な理論発見や学習の保証はない。
- 現在の検証器が扱う仮説の型は限られる。**素数を直接予測・生成する新しい数学的実験型は未実装**。
- 小さな整数世界の拡張は、定義と実験方法が未確定のためまだ自動検証しない。
- 有限範囲で反例がないことは数学的証明ではない。既知の性質との照合も自動判定できない。
- AIの説明と構造化された検証条件の一致、学術的新規性は未確認。
- 研究データは `data/research.json` と `data/runs/` に保存。

## 次の開発候補
1. 仮説の同値性・既知の初等事実の自動除外
2. 素数予測・生成に関する安全な実験型と、訓練範囲外での検証
3. 仮説の改良履歴を親子関係で記録
4. 数学的証明の有無を別管理し、研究成果を段階表示
