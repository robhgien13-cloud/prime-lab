# 構造化仮説の有限検証（試作）

AIの自由文をPythonコードとして実行しない。検証対象を次のJSON形式に限定する。

```json
{"kind":"prime_residue","limit":100,"modulus":6,"residues":[1,5]}
```

これは「6より大きい素数を6で割った余りが1または5に含まれるか」を、100以下の対象に限って検査する。

現在の種類:
- `prime_residue`: 素数をmで割った余り
- `prime_last_digit`: 素数の剰余（現時点では汎用の剰余と同じ意味。末尾の数字を調べる場合はmodulus=10）
- `prime_gap_divisible`: 隣接する素数の差をmで割った余り

制約: 20 <= limit <= 10000, 2 <= modulus <= 100, residuesは重複なしの整数配列。未知のキー、コード、任意の関数実行は許可しない。

**重要な限界**: AIの文章と構造化JSONが同じ数学的意味かどうかは未検証。JSONが検査できたことを、元のAI仮説の検証完了と混同しない。一般的な証明や新規性の確認は行わない。

次の実装: AIが候補JSONを出し、別の検査段階で定義の一致を確認する。テスト通過後、再現可能な実験結果と一般向け説明を記録する。
