# AI提案と数学検証の接続 — 初期仕様

現在のシステムでは、AIが自由文で生成した仮説を直接計算プログラムに変換しません。生成コードを実行しないためです。

`src/prime_lab/verification.py` は、3つの既知の命題に対応する許可リスト型の有限検証器です。入力は `{"kind":"prime_mod_6","limit":1000}` のような厳密なJSONです。最大10000まで。

`src/prime_lab/bridge.py` は、AIの提案と検証テンプレートの結果を並べて保存するための初期接続部です。**AIの仮説とテンプレートが数学的に同一かは未確認**なので、検証済みと表示しません。

未実装:
- 自由文仮説から形式命題への安全で正確な変換
- その命題を独立に確認する仕組み
- 文献検索・新規性判定
- 自動的な日次実行と結果コミット
- 異分野比較・メタ研究
- API設定とモデル接続

受入条件: 自由文からの自動変換で数学的意味が変わる可能性を排除するまで、「AI仮説を検証済み」と表示しない。
