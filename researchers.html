RESEARCH METHODS · PUBLIC PROTOCOL

研究者の方へ

PRIME LABは、生成AIによる素数の仮説提案と、Pythonによる有限範囲の反例探索を組み合わせる公開実験です。数学的な新発見を達成したと主張するものではありません。

実装状況（2026年10月）

Gemini APIによる構造化仮説の提案と有限検証を手動実行で確認済み。1日10件の定期有限検証はGitHub Actionsに設定しましたが、こちらはAIによる仮説生成ではありません。スケジュール実行の成功は未確認です。

1. 研究目的と検証可能な問い

生成AIがどのような素数の規則性を提案するか、反例が見つかるか、既出の条件を繰り返すかを記録します。目的は「有限実験の再現可能性」「失敗を含む公開」「仮説の由来の追跡」です。

2. 仮説の形式

自由なPythonコードはAIに実行させず、許可されたJSON条件だけを受け付けます。現在の対象は素数の剰余、素数の末尾、隣接素数間隔の剰余です。

{"kind":"prime_residue","limit":1000,"modulus":6,"residues":[1,5]}

対象範囲は20〜10000、法は2〜100。入力型と値域を検証します。数値検証の実装は structured.py にあります。

3. 実験の流れ

提案または日付由来の条件生成 → 入力検査 → 素数列生成 → 指定した剰余条件の有限検査 → 最初の反例または検査範囲の記録 → JSON公開、という順序です。計算上の「反例なし」は定理の証明ではありません。

4. AI提案と定期検証の違い

区分内容
AI提案Gemini APIで条件を1件提案。手動実行。無料枠の利用状況に依存。
日次10件日付から決定論的に10条件を生成し検証。API呼び出しなし。新規性の保証なし。
初期試験10件あらかじめ決めた固定条件。研究装置の動作試験。

5. 重複・先行研究・限界

保存済みJSONの条件が完全一致する場合は重複として記録します。ただし論理的に同値な命題、既知の初等定理、先行研究との重複は自動判定できません。AIが書いた動機とJSON条件の意味の一致も未確認です。学術的新規性や証明は第三者による検討が必要です。

6. 再現方法

python -m unittest discover -s tests -v
python -m src.prime_lab.daily

公開JSONは data/research.json、個別の検証記録は data/runs にあります。コードと仕様は GitHubリポジトリ で公開しています。

7. 協力・批判の歓迎

検証方法の欠陥、既知の定理との一致、反例、研究対象の改善提案を歓迎します。ご指摘は GitHub Issues へ。成果の学術的な新規性は未確認です。
